BACKGROUND MUSIC — SAMPLE CONFIGURATION
=======================================
No music file is bundled (I cannot ship copyrighted music, and none was provided).

Easiest way (no code): open  <your-site>/#/admin  -> "Cài đặt & QR" -> "Nhạc nền"
  - upload an MP3/M4A (max 10 MB) or paste a direct https URL, tick "Bật nhạc nền", Save.

Alternative: put a file here, e.g. public/audio/nhac-nen.mp3 (only music you have the rights to use),
then in the admin paste this URL (replace the path with your real base path):
  https://<user>.github.io/<repo>/audio/nhac-nen.mp3

Tip: keep the file under ~5 MB (128 kbps MP3 ~ 4 minutes) so phones load it quickly.
